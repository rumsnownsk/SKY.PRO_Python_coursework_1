# Coursework: Финансовый трекер и аналитика расходов

Проект представляет собой консольное приложение на Python для учёта личных финансов и построения аналитических отчётов по транзакциям.

## Структура проекта

coursework_1/ 
├── data/ # Исходные данные (например, operations.xlsx) 
├── logs/ # Логи работы приложения (log_views.log) 
├── src/ # Основной код приложения 
│ ├── config.py # Конфигурация и настройки 
│ ├── main.py # Точка входа 
│ ├── reports.py # Логика формирования отчётов и логирование 
│ ├── services.py # Бизнес-логика и внешние интеграции 
│ ├── utils.py # Вспомогательные функции 
│ └── views.py # Форматирование вывода для пользователя 
├── tests/ # Юнит-тесты (pytest) 
├── tmp/ # Временные файлы: кэш API и JSON-отчёты 
├── .env # Переменные окружения 
└── README.md

## Основные возможности

### Аналитика расходов
Модуль `src/reports.py` предоставляет функции для детального анализа трат:
*   **`spending_by_category`**: формирование отчёта по конкретной категории за последние 3 месяца. Результат сортируется по дате (от новых к старым) и сохраняется в JSON.
*   **`spending_by_weekday`**: расчёт среднего чека по дням недели за последние 3 месяца.

### Интеграции и данные
Модуль `src/services.py` отвечает за получение внешних данных и работу с источниками транзакций.

### Контроль и отладка
В проекте реализовано структурированное логирование (`logging`):
*   **INFO**: ключевые этапы работы (запуск функций, параметры фильтрации, количество обработанных строк).
*   **WARNING**: некритичные проблемы (пустой входной DataFrame, некорректный формат даты).
*   **ERROR**: критические ошибки (не удалось сохранить файл, неверный тип данных).

### Кэширование
Для оптимизации запросов к внешним API используется папка `tmp/` (файлы `cache_*.json`), что позволяет избежать лишних обращений к сети при повторном запуске.

## Быстрый старт

### Требования
*   Python 3.12+
*   Менеджер зависимостей `poetry`

### Установка и запуск

1.  Установите зависимости:
    ```bash
    poetry install
    ```

2.  Настройте переменные окружения (скопируйте `.env.example` в `.env` и отредактируйте):
    ```bash
    cp .env.example .env
    ```

3.  Запустите приложение:
    ```bash
    poetry run python -m src.main
    ```
